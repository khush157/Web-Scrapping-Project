# Flipkart Web Scraping Project

This project is a Python-based web scraper that collects product information from Flipkart using the requests and BeautifulSoup libraries.
It extracts product details such as:

📱 Product Name

💰 Price

⭐ Rating

🔗 Product Description

The collected data can be saved into a CSV file for further analysis.

🚀 Features

✔ Scrapes multiple products from Flipkart search results
✔ Supports pagination
✔ Exports extracted data into a structured CSV file
✔ Uses custom User-Agent headers to avoid blocking
✔ Handles missing values safely

🛠️ Tech Stack
* Technology	Purpose
* Python	Programming Language
* Requests	Fetching webpage HTML
* BeautifulSoup (bs4)	Parsing HTML
* Pandas	Store & export data

🔒 Note & Disclaimer

Flipkart content is protected; scraping should only be used for personal learning purposes

Avoid scraping too frequently to prevent IP blocking

Always follow website terms of service
